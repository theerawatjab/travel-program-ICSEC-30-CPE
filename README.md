# HuaHin.Trip: หัวหิน – สามร้อยยอด 1 วัน

เว็บหน้าเดียวแสดงโปรแกรมท่องเที่ยว เขียนด้วย PHP + CSS + JavaScript ล้วน

## รันบนเครื่อง
ต้องมี PHP 8 ขึ้นไป

```bash
php -S localhost:8000
```

เปิด http://localhost:8000

## แก้เนื้อหา
แก้ไฟล์ `data/trip.php` ไฟล์เดียว: ชื่อทริป สไลด์ วัน สถานที่ เวลา และรูป

- รูปจาก Unsplash: `'image' => 'unsplash:PHOTO_ID'`
- รูปของตัวเอง: วางไฟล์ใน `assets/images/` แล้วใส่ `'image' => 'assets/images/ชื่อไฟล์.jpg'`

## สองภาษา
เว็บเปิดเป็นภาษาอังกฤษก่อน กดปุ่ม EN / ไทย บนเมนูเพื่อสลับ หรือเปิดลิงก์ `?lang=th` ตรง ๆ ก็ได้
ข้อความทริปเขียนเป็น `['en' => '...', 'th' => '...']` ใน `data/trip.php` ส่วนข้อความบนปุ่มและเมนูอยู่ที่ `data/ui.php`
