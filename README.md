# HuaHin.Trip: หัวหิน – สามร้อยยอด 1 วัน

เว็บหน้าเดียวแสดงโปรแกรมท่องเที่ยว เขียนด้วย PHP + CSS + JavaScript ล้วน

## รันบนเครื่อง
ต้องมี PHP 8 ขึ้นไป

**ใช้ XAMPP:** วางโฟลเดอร์ไว้ใน `htdocs` เปิด Apache แล้วเข้า http://localhost/travel-program-ICSEC-30-CPE/

**ใช้ PHP อย่างเดียว:**

```bash
php -S localhost:8000
```

เปิด http://localhost:8000

## โครงสร้างไฟล์

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `data/trip.php` | ข้อมูลทริปทั้งหมด: ชื่อ สไลด์ โปรแกรม เวลา รูป ติดต่อ |
| `data/ui.php` | ข้อความบนปุ่มและเมนู |
| `assets/images/` | รูปทั้งหมดของเว็บ และไอคอนเว็บ (`travel.png`) |
| `index.php` | โครงหน้าเว็บ (ปกติไม่ต้องแก้) |
| `assets/css/style.css`, `assets/js/main.js` | หน้าตาและการทำงานของเว็บ |
| `includes/helpers.php` | ฟังก์ชันช่วย |

## แก้เนื้อหา
แก้ที่ `data/trip.php` ไฟล์เดียว แบ่งเป็นส่วนต่าง ๆ ดังนี้

| ส่วนในไฟล์ | แสดงตรงไหนบนเว็บ |
|---|---|
| `'title'`, `'tagline'` | ชื่อทริปและคำโปรย |
| `'facts'` | กล่องสรุป ระยะเวลา จุดหมาย รับ-ส่ง ระยะทาง |
| `'slides'` | สไลด์ใหญ่ด้านบน |
| `'days'` → `'stops'` | โปรแกรม / กำหนดการด้านล่าง |
| `'contact'` | ส่วนติดต่อเรา |
| `'credits'` | เครดิตรูปภาพ |

ข้อควรรู้:

- **ลำดับสไลด์ = ลำดับที่เขียนในไฟล์** ระบบไม่ได้เรียงตามเวลาให้ ถ้าจะเปลี่ยนลำดับ ให้ย้ายทั้งก้อน `[ ... ],`
- **`'slides'` กับ `'days'` เป็นข้อมูลคนละชุด** ถ้าเปลี่ยนเวลา ชื่อ หรือรูปของสถานที่ ต้องแก้ทั้งสองที่ให้ตรงกัน
- เวลาใช้รูปแบบ 24 ชม. `"HH:MM"` ระบบคำนวณระยะเวลาให้เอง
- จุดแวะสั้น ๆ (เช่น รับที่โรงแรม) ใช้ `'type' => 'note'` มีแค่ `time` กับ `text`

## รูปภาพ
วางไฟล์รูปใน `assets/images/` แล้วใส่ชื่อในช่อง `'image'` ของ `data/trip.php`

```php
'image' => 'assets/images/phraya-nakhon-cave.jpg',
```

รูปที่ใช้อยู่ตอนนี้:

| ไฟล์ | ใช้ที่ |
|---|---|
| `khao-sam-roi-yot.jpg` | สไลด์ เขาสามร้อยยอด |
| `phraya-nakhon-cave.jpg` | สไลด์ ถ้ำพระยานคร |
| `bang-pu-beach.jpg` | สไลด์ หาดบางปู |
| `thung-sam-roi-yot.jpg` | สไลด์ ทุ่งสามร้อยยอด |
| `eureka-cafe.jpg` | สไลด์ Eureka Cafe |
| `phraya-nakhon-cave-card.jpg` | การ์ดโปรแกรม ถ้ำพระยานคร |
| `bang-pu-beach-card.jpg` | การ์ดโปรแกรม หาดบางปู |
| `thung-sam-roi-yot-card.jpg` | การ์ดโปรแกรม ทุ่งสามร้อยยอด |
| `eureka-cafe-card.jpg` | การ์ดโปรแกรม Eureka Cafe |
| `contact-bg.jpg` | พื้นหลังส่วนติดต่อ |
| `travel.png` | ไอคอนเว็บ (favicon) ตั้งค่าใน `index.php` |

วิธีเปลี่ยนรูป: ตั้งชื่อไฟล์ใหม่ให้ตรงกับชื่อเดิมแล้ววางทับได้เลย หรือจะใช้ชื่อใหม่ก็ได้ แต่ต้องแก้ชื่อใน `data/trip.php` ด้วย

- ชื่อไฟล์ใช้ภาษาอังกฤษตัวพิมพ์เล็ก ไม่มีเว้นวรรค ใช้ `-` คั่นคำ (บนเซิร์ฟเวอร์ Linux ตัวพิมพ์เล็ก-ใหญ่ต้องตรงกับไฟล์จริง)
- รูปสไลด์และพื้นหลัง: แนวนอน กว้างราว 1600–2000 px / รูปการ์ด: ราว 800–1200 px
- บีบอัดให้ไม่เกินราว 500 KB ต่อรูป เว็บจะโหลดเร็ว
- ถ้าหารูปไม่เจอ เว็บจะซ่อนรูปนั้นและแสดงสีพื้นหลังแทน
- เปลี่ยนรูปแล้วอย่าลืมแก้ `'credits'` ให้ตรงกับเจ้าของรูปจริง

### ใช้รูปจาก Unsplash แทนไฟล์ในเครื่อง
ใส่รหัสรูปแทน path ได้:

```php
'image' => 'unsplash:PHOTO_ID',
```

- หา `PHOTO_ID`: เปิดรูปใน unsplash.com ลิงก์จะเป็นแบบ `unsplash.com/photos/ชื่อรูป-XyZ123` ใช้ส่วนท้ายหลัง `-` ตัวสุดท้าย คือ `XyZ123`
- ดูรูปต้นฉบับจากรหัส: เปิด `https://unsplash.com/photos/PHOTO_ID`
- ใช้ได้เฉพาะรูปที่มีปุ่ม "Download free" รูป Unsplash+ (ป้าย +) จะแสดงไม่ขึ้น

ใส่ URL เต็มของรูปจากเว็บอื่นก็ได้ เช่น `'image' => 'https://example.com/photo.jpg'`

## สองภาษา
เว็บเปิดเป็นภาษาอังกฤษก่อน กดปุ่ม EN / ไทย บนเมนูเพื่อสลับ หรือเปิดลิงก์ `?lang=th` ตรง ๆ ก็ได้

ข้อความทริปเขียนเป็น `['en' => '...', 'th' => '...']` ใน `data/trip.php` ถ้าข้อความเหมือนกันทั้งสองภาษา (เช่นชื่อร้าน) ใส่เป็นข้อความธรรมดาได้เลย ส่วนข้อความบนปุ่มและเมนูอยู่ที่ `data/ui.php`
